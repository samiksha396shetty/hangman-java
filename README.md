# Hangman Game

A simple Java console-based Hangman game where players guess letters to find the hidden word before the hangman is completed.

## Features
- Single-player mode with random words from a dictionary file
- Two-player mode
- Letter-by-letter guessing
- Full word guessing option
- Hangman visual based on wrong attempts
- Win/Lose detection

## Technologies Used
- Java
- ArrayList
- Scanner Class
- File Handling
- Random Class

## Purpose
This project was created to practice Java programming concepts such as loops, methods, conditions, file handling, collections, and user interaction through a fun terminal-based game.

## How to Run
1. Open the project in any Java IDE like IntelliJ IDEA, Eclipse, or VS Code.
2. Make sure the dictionary text file path is correct in the program.
3. Run the `project1` file.
